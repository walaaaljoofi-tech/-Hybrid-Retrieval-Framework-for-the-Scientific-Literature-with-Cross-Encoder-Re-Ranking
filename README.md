# -Hybrid-Retrieval-Framework-for-the-Scientific-Literature-with-Cross-Encoder-Re-Ranking
Semantic retrieval has become increasingly important for scientific literature search due
to the limitations of traditional lexical methods, such as BM25, in capturing contextual 
relevance. Recent transformer-based language models provide domain-aware semantic 
representations that offer new opportunities for improving retrieval effectiveness. This 
paper presents a systematic evaluation of dense semantic retrieval on the SciFact benchmark 
and compares lexical, dense, hybrid, and cross-encoder retrieval pipelines within a unified 
framework. Experimental results show that while SciBERT-based dense retrieval captures 
semantic information, it exhibits limitations in identifying fact-based scientific claims when 
used in isolation. Integrating lexical and dense retrieval through hybrid fusion, followed 
by cross-encoder re-ranking, leads to consistent performance improvements
